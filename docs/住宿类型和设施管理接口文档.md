# 住宿类型和设施管理接口文档

## 1. 概述

本文档详细说明了住宿类型和设施管理的相关接口。为了更好地管理住宿信息，我们将住宿类型和设施信息独立出来，形成单独的管理接口，便于维护和扩展。

## 2. 数据库表结构

### 2.1 住宿类型表 (accommodation_types)

| 字段名 | 类型 | 描述 |
|--------|------|------|
| id | int | 住宿类型ID |
| name | varchar(50) | 类型名称 |
| description | text | 类型描述 |
| create_time | datetime | 创建时间 |
| update_time | datetime | 更新时间 |

### 2.2 住宿设施表 (accommodation_facilities)

| 字段名 | 类型 | 描述 |
|--------|------|------|
| id | int | 设施ID |
| name | varchar(50) | 设施名称 |
| description | text | 设施描述 |
| icon | varchar(255) | 设施图标 |
| create_time | datetime | 创建时间 |
| update_time | datetime | 更新时间 |

### 2.3 住宿设施关联表 (accommodation_facility_relations)

| 字段名 | 类型 | 描述 |
|--------|------|------|
| id | int | 关联ID |
| accommodation_id | int | 住宿ID |
| facility_id | int | 设施ID |
| create_time | datetime | 创建时间 |
| update_time | datetime | 更新时间 |

## 3. 住宿类型管理接口

### 3.1 分页查询住宿类型

#### 请求地址
```
POST /accommodation-types/page
```

#### 请求方法
POST

#### 请求参数
```json
{
  "pageNum": 1,
  "pageSize": 10,
  "query": {
    "name": "酒店"  // 可选，类型名称模糊查询
  }
}
```

#### 响应数据
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "total": 100,
    "pageNum": 1,
    "pageSize": 10,
    "list": [
      {
        "id": 1,
        "createTime": "2025-11-29 10:00:00",

        "name": "酒店",
        "description": "提供标准化住宿服务的商业住宿设施"

  }
}
```

## 7. 错误码说明

| 错误码 | 描述 |
|--------|------|
| 200 | 请求成功 |
| 400 | 请求参数错误 |
| 401 | 未授权访问 |
| 403 | 权限不足 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

## 8. 注意事项

1. 所有时间字段格式为：`yyyy-MM-dd HH:mm:ss`
2. 新增和修改接口会对名称字段进行非空验证
3. 删除操作为逻辑删除，不会真正从数据库中移除数据
4. 分页查询页码从1开始计数
5. 管理员接口需要相应的管理员权限才能访问
6. 住宿设施关联通过中间表实现，查询时自动包含关联的设施信息
